# Заметки

Кратко про JS и TypeScript — для себя.

## JS (JavaScript)

Обычный язык, который выполняется в браузере или в Node.

```js
function sum(a, b) {
  return a + b;
}

sum(2, 3); // ок
sum('2', 3); // тоже ок → "23"
```

JS не проверяет типы: он «доверяет» и может вести себя неожиданно.

---

## TS (TypeScript)

Надстройка над JS: добавляет типы, чтобы ловить ошибки заранее.

```ts
function sum(a: number, b: number) {
  return a + b;
}

sum(2, 3); // ок
sum('2', 3); // ошибка ещё до запуска
```

---

## Главная разница

| JS                           | TS                          |
| ---------------------------- | --------------------------- |
| Нет типов                    | Есть типы                   |
| Ошибки — во время выполнения | Ошибки — до запуска         |
| Проще начать                 | Надёжнее в больших проектах |

---

## Важно (часто путают)

TypeScript не выполняется напрямую в браузере/Node как есть. Сначала компиляция в JS:

```text
.ts → компиляция → .js → выполнение
```
