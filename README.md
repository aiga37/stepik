# TS + Playwright — учебный репозиторий

Здесь проходится курс **«Автоматизация тестирования с Playwright на JS/TS»** (Stepik) и хранятся решения заданий.

План: ближе к концу курса в этом же репозитории собрать **итоговый проект** по автотестам.

## Что внутри

- Упражнения и черновики — по ситуации в корне или в отдельных папках по мере роста проекта.
- Личные заметки по JS/TS: [NOTES.md](./NOTES.md)
- Команды для терминала: [COMMANDS_CHEATSHEET.md](./COMMANDS_CHEATSHEET.md)

## Быстрый старт (когда появится Playwright-проект)

Ориентировочно (после `npm init` и установки Playwright в проект):

```bash
npx playwright test
```

Точные команды зависят от того, как оформит финальное задание курс — обновлю README под реальную структуру, когда проект будет готов.
