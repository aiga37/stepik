## 🔹 JS (JavaScript)

👉 обычный язык, который выполняется в браузере или Node

```js
function sum(a, b) {
  return a + b;
}

sum(2, 3); // ок
sum('2', 3); // тоже ок 😅 → "23"
```

JS **не проверяет типы**
Он “доверяет тебе” и может делать странные вещи.

---

## 🔹 TS (TypeScript)

👉 это **надстройка над JS** (расширение, но тоже язык)

Он добавляет **типы**, чтобы ловить ошибки заранее.

```ts
function sum(a: number, b: number) {
  return a + b;
}

sum(2, 3); // ок
sum('2', 3); // ❌ ошибка ещё ДО запуска
```

---

## 🔹 Главная разница

| JS                           | TS                          |
| ---------------------------- | --------------------------- |
| Нет типов                    | Есть типы                   |
| Ошибки — во время выполнения | Ошибки — до запуска         |
| Проще начать                 | Надёжнее в больших проектах |

---

## 🔹 Важный момент (часто путают)

👉 TypeScript **не запускается напрямую**

Он сначала превращается в JS:

```text
.ts → компиляция → .js → выполняется
```
